# TastyCoffee watcher

Скрипт мониторинга ассортимента и цен 

Возможности:
- Обходит все страницы `/coffee?page=N`
- Сохраняет снапшот товаров в JSON
- Показывает новые / удалённые товары и изменения цен
- Классифицирует вид кофе через OpenAI (`Зерно кофе`, `Капсулы`, `Дрип-пакеты` и т.д.)
- Генерирует Excel-файл `tastycoffee_report.xlsx`:
  - новые товары — вся строка зелёная
  - изменившаяся цена — зелёная только ячейка с текущей ценой
